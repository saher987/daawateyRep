# frontend

React + Vite + TypeScript SPA, wrapped with Capacitor for Android (iOS later).

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Environment variables

Firebase web config is injected via `VITE_FIREBASE_*` env vars — see `.env.example`
once it's added. Never commit `.env.staging` / `.env.production`.

## Android

The Android project lives in `android/` (generated by Capacitor — don't hand-edit
generated files under `android/app/src/main/assets`, they're overwritten by sync).

All debug builds — local Android Studio or CI — sign with one shared keystore
checked into this repo (`android/app/debug.keystore`, wired up in
`android/app/build.gradle`). This keeps the SHA-1 fingerprint identical
everywhere, so it only needs registering with Firebase once. A debug keystore
can't sign a Play Store release and uses Android's universally-known default
debug password — nothing sensitive about committing it.

Shared debug keystore SHA-1: `05:15:76:8F:02:4F:45:BA:5C:37:6D:2B:37:1D:C0:C8:24:04:1C:9C`

### One-time setup (already done for `daawatey-staging`)

Firebase Console → `daawatey-staging` → Project settings → **Add app** → Android:
- Package name: `com.daawatey.app`
- Debug signing certificate SHA-1: the value above
- Download the generated **`google-services.json`**

Locally, place it at `frontend/android/app/google-services.json` (gitignored —
per-environment config, like `.env.staging`).

For CI builds (see `.github/workflows/android-build.yml`), the same file's
contents are base64-encoded and stored as the `GOOGLE_SERVICES_JSON_BASE64`
secret on the `staging` GitHub Environment:
```bash
base64 -w0 google-services.json   # macOS: base64 -b0, or just base64 with no wrap flag
```
Paste the output as that secret's value.

### Building/running locally (needs Android Studio)

```bash
npm run android:sync   # build web assets + sync into the Android project
npm run android:open   # same, then opens Android Studio
```

From Android Studio: pick a device/emulator and hit Run. Any time you change
frontend code, re-run `npm run android:sync` (or just `android:open`) before
running again — the native project only sees whatever was last synced.

### Building in the cloud (no Android Studio needed)

Repo → **Actions** → **Build Android APK** → **Run workflow**. When it
finishes, download the `daawatey-debug-apk` artifact from the run's summary
page, transfer the `.apk` to an Android phone, and tap to install it (you'll
need to allow "install from unknown sources" once). Email/password sign-in
works immediately; Google sign-in works too, since this build uses the same
registered SHA-1 as everything else.
