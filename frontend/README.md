# frontend

React + Vite + TypeScript SPA, wrapped with Capacitor for Android (iOS later).

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Environment variables

Firebase web config is injected via `VITE_FIREBASE_*` env vars — see `.env.example`
once it's added. Never commit `.env.staging` / `.env.production`.

## Android

The Android project lives in `android/` (generated by Capacitor — don't hand-edit
generated files under `android/app/src/main/assets`, they're overwritten by sync).

### One-time setup (per machine)

1. Install **Android Studio** (includes the Android SDK): https://developer.android.com/studio
2. Open this `frontend/android` folder in Android Studio once, so it downloads
   the SDK platform/build-tools and generates your local debug keystore
   (`~/.android/debug.keystore`).
3. Get your debug keystore's SHA-1 fingerprint (needed for Google Sign-In to work):
   ```bash
   keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android -keypass android
   ```
   Copy the `SHA1:` value.
4. Firebase Console → `daawatey-staging` → Project settings → **Add app** → Android:
   - Package name: `com.daawatey.app`
   - Paste the SHA-1 from step 3 under "Debug signing certificate SHA-1"
   - Download the generated **`google-services.json`**
   - Place it at `frontend/android/app/google-services.json` (gitignored — per-environment, like `.env.staging`)

### Building/running

```bash
npm run android:sync   # build web assets + sync into the Android project
npm run android:open   # same, then opens Android Studio
```

From Android Studio: pick a device/emulator and hit Run. Any time you change
frontend code, re-run `npm run android:sync` (or just `android:open`) before
running again — the native project only sees whatever was last synced.
